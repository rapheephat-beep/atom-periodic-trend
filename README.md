## กิจกรรมทั้ง 8 (ตรงตามใบกิจกรรม 6)
| ข้อ | กิจกรรม | | ข้อ | กิจกรรม |
|---|---|---|---|---|
| 1.1 | ขนาดอะตอม ตามหมู่ | | 3.1 | IE₁ ตามหมู่ |
| 1.2 | ขนาดอะตอม ตามคาบ | | 3.2 | IE ลำดับที่ 1, 2, 3, … |
| 2.1 | ขนาดไอออนลบ | | 4 | EA ตามหมู่ |
| 2.2 | ขนาดไอออนบวก | | 5 | EN ตามหมู่ |

**สิ่งที่ต่างจากรุ่นแรก**
- **ล็อกลำดับ** ต้องยืนยันคำทำนายก่อน ตารางหลักฐานจึงเปิด — ข้อกล่าวอ้างจึงเป็นการทำนายจริง ไม่ใช่การอ่านคำตอบมาก่อน
- **ตารางหลักฐานเป็นช่องว่าง** นักเรียนอ่านค่าจากแบบจำลองมากรอกเอง กราฟขยับตามที่กรอก
- **ตรวจคำอธิบายให้เป็นระดับ 0–3** พร้อมบอกว่าขาดประเด็นไหนและควรทำอะไรต่อ โดยไม่เฉลย
- **เก็บทุกร่างที่แก้** พร้อมเวลาและระดับ → เห็นพัฒนาการ ไม่ใช่แค่คะแนนสุดท้าย
- **หน้าครู** สร้างลิงก์ประจำห้องจากรายชื่อ และรวมไฟล์งานทั้งห้องเป็นตาราง + CSV
