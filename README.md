## 5 กิจกรรม
1. **เทียบรัศมีอะตอม** — เลือก 2 ธาตุ เปรียบเทียบระดับพลังงานหลัก จำนวนอิเล็กตรอน ประจุนิวเคลียส และรัศมี
2. **สร้างไอออน & ขนาด** — ดึง/เติมอิเล็กตรอนทีละตัว ดูไอออนบวกเล็กลง–ไอออนลบใหญ่ขึ้น
3. **ดึงเวเลนซ์ & IE** — ดึงเวเลนซ์อิเล็กตรอนพร้อมค่าพลังงานไอออไนเซชัน เปรียบเทียบ 2 ธาตุ
4. **IE ลำดับที่ 1, 2, 3…** — ดูค่า IE ต่อเนื่องของธาตุเดียว พร้อมไฮไลต์ "จุดกระโดด"
5. **ไอออนลบ & EA** — เทียบขนาดไอออนลบ พร้อมค่าสัมพรรคภาพอิเล็กตรอน
